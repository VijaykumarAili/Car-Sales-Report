# Car Sales Report

This repository contains a comprehensive Power BI dashboard for analyzing car sales data. It provides detailed insights into various performance metrics and sales trends to support data-driven decision-making.

## 📊 Project Content

*   **`Car sales report.pbix`**: The primary Power BI interactive dashboard file, populated with data and visualizations.
*   **`Car Dashboard Source.xlsx`**: The raw initial dataset in Excel format used as the data source for the Power BI dashboard.

## 🌟 Features included in the Dashboard

*   **Sales Tracking**: Overall summary of total sales, total revenue generated, and total car units sold over specific periods.
*   **Trend Analysis**: Monitoring of month-over-month (MoM) and year-over-year (YoY) sales variations.
*   **Drill-Down Capabilities**: Dive deeper into categories such as car models, body types, dealership regions, and brands.
*   **Interactive Slicers**: Dynamic user filtering of data by dates or vehicle specification arrays.

## 🛠️ Setup & Usage

1.  **Software Requirement**: Ensure you have [Power BI Desktop](https://powerbi.microsoft.com/desktop/) installed.
2.  **Launching the Dashboard**: Double-click on `Car sales report.pbix` to open the file directly in Power BI Desktop.
3.  **Updating Data Connection (Optional)**: If you need to refresh the data or the connection breaks, open the `.pbix` file, click on **Transform Data** > **Data source settings**, and modify the source to point directly to the local absolute path of `Car Dashboard Source.xlsx`.
